# Gemini compatibility pointer

This file exists so Gemini-based coding tools that automatically inspect `Gemini.md` land on the current project instructions.

**Do not treat this file as a separate source of truth.**

Read, in order:

1. `AGENTS.md`
2. the newest relevant entry in `DEV_JOURNAL.md`
3. `docs/README.md`
4. only the canonical documentation relevant to the task

Current architecture, roadmap, migration decisions, testing requirements, and security boundaries live behind that documentation map.

In particular, historical instructions that recommended browser-stored API keys or treated `docs/MASTER_PLAN.md` as authoritative are superseded.
