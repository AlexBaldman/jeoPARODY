# uINVERSE

The proposed operating system for a connected body of games, tools, characters, learning systems, businesses, and physical experiences. The graph is also the portfolio: every artifact can reveal what made it, where it appears, what it taught, and what it can become next.

## Four-part model

| Layer | Owns | Never owns |
|---|---|---|
| Atlas | canonical entities and relationships | workflow state |
| Factory | repeatable transformations and gates | permanent identity facts |
| World | user-facing experiences | duplicate shared systems |
| Showcase | derived portfolio and promotion views | canonical truth |
