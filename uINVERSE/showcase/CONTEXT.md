# Showcase — derived promotion layer

One job: turn the generated graph into truthful, traceable portfolio views.

## Inputs
- Working: `../registry/graph.json`
- Reference: `rules/promotion.md`

## Process
1. Select an entity and its verified incoming and outgoing relationships.
2. Show provenance, appearances, dependencies, produced artifacts, and evolution.
3. Generate channel-specific views without changing canonical records.

## Outputs
- Portfolio, site, GitHub, social, or in-world views in a future run folder

## Human check
Verify that every claim resolves to a canonical record or provenance pointer before publishing.
