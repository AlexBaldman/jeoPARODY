# 01_intake — bound and inventory one source packet

## Inputs
- Working: source material supplied for this run
- Reference: `../../../../atlas/_meta/entity-schema.md`

## Process
1. Assign a run ID and record source locations, dates, access limits, and scope.
2. Copy or link the bounded source packet into `output/`.
3. Write `manifest.md` with one line per source.

## Outputs
- `manifest.md` and bounded source files in `output/`

## Human check
Confirm the packet is complete enough for this run and excludes material outside its authorized scope.
