# WARP compatibility pointer

This file exists for Warp-based development tools that automatically inspect `WARP.md`.

**Project law and current architecture do not live here.**

Read, in order:

1. `AGENTS.md`
2. the newest relevant entry in `DEV_JOURNAL.md`
3. `docs/README.md`
4. only the canonical documentation relevant to the task

Useful commands are listed in the root `README.md` and `package.json`.

Historical Warp guidance about direct browser API keys, old question paths, planned browser testing, and older architecture assumptions is superseded by the canonical docs map.
