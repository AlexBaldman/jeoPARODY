# Brazillionaire

**Status:** PRESSURE_TEST

Phrase-first creative language-learning game/world. Existing broader concept includes translation popovers, memory cards, mnemonics and pixel-art presentation.

## Stage/world insight from the cypher

Scenes can be modeled semantically as settings/backgrounds + actors + props + interactions, with a Language/Experience Director deciding how learning state affects presentation. The same semantic place may eventually project as illustrated scene, 2D layer, RPG/adventure layer, 3D/open-world layer, or choose-your-own-adventure prose.

A mall or arcade inside Brazillionaire can host discoverable assets and tiny in-world games/Easter eggs. These should remain optional world content, not architectural dependencies.

## Pressure test

Brazillionaire is valuable because it stresses multi-projection scenes and learning-state adaptation in ways JeoPARODY does not. Use it only after Stage primitives are proven by actual JeoPARODY needs.
