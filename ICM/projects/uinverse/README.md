## Core doctrine

> **The uINVERSE is a world engine whose games are temporary arrangements of reusable systems.**

Prefer composable primitives, stable contracts, adapters, reusable factories, and proven external systems over repeated bespoke implementations. Don't put a hat on a hat, and don't rebuild the wheel more often than necessary.

## Guardrail

Do not attempt to implement the entire cosmology at once. Build reusable primitives when a real world/project needs them, then promote proven capabilities into the shared substrate. uINVERSE should emerge from repeated useful machinery rather than become an architectural theme park whose main attraction is architecture.
