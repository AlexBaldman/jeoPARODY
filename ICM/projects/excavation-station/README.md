# Excavation Station

**Status:** PRESSURE_TEST

Project archaeology as a first-class place/system. Search commits, branches, prototypes, conversations, screenshots, assets, abandoned architecture and notes for valuable fossils.

## Expedition model

```text
QUERY / MISSION
→ SEARCH STRATA
→ SURFACE FOSSILS
→ COMPARE TO CURRENT TRUTH
→ CLASSIFY
→ PRESERVE / EXTRACT / RESTORE / BURY
→ RECORD PROVENANCE
```

Git history can become geological strata/tunnels. Agent searches become expeditions. Recovered artifacts feed ICM, asset registry, migration plans, or active implementation only after classification.

## Temporal geography

```text
OBSERVATORY — possible futures
      ↓
DESK / WORKSHOP — active creation
      ↓
EXCAVATION STATION — project archaeology
      ↓
DEEP ARCHIVE — preserved history
```
