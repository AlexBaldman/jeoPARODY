# ALgoRHYTHM B

**Status:** SEED  
**Role:** semantic-chain freestyle game/interface

## Seed

A game/tool where rhyme and freestyle are represented as traversals through a living semantic graph. Preserve not just the output bars but the path that generated them.

```text
concept
→ association
→ phonetic mutation
→ double meaning
→ proper noun
→ callback
→ next viable edge
```

Possible relationship labels: rhyme, slant rhyme, homophone, near-homophone, semantic association, cultural reference, grammatical mutation, name mutation, double entendre, callback, memory conflict.

## Mandela-effect class

A useful future Stool Sample / ALgoRHYTHM class is `Mandela Effect Bars`: intentionally exploring memory-graph desync, confident reconstruction, altered recollection, and version-conflict metaphors. Keep fictional/uncertain recollections clearly marked rather than laundering them into factual claims.

## Interface hypothesis

Visualize the graph live while a player performs. Score or illuminate surprising but defensible transitions, callbacks, semantic distance, reuse of dormant nodes, and recovery from dead ends. The path itself is creative data.

## Relationship to Stool Samples

ALgoRHYTHM B can provide traversal/performance mechanics; Stool Samples can provide structured joke/performance specimens and analysis. They may share primitives without becoming one product prematurely.

## Next lead domino

Define a minimal `SemanticEdge` vocabulary and manually encode one existing freestyle chain as a fixture. No generation engine yet.
